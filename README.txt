LOCAL PREVIEW
1. Open Terminal in this folder.
2. Run: python3 -m http.server 8088
3. Open: http://127.0.0.1:8088

GITHUB PAGES
1. Create a GitHub repository.
2. Upload the CONTENTS of this folder to the repository root so index.html is at the top level.
3. In GitHub: Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root).
5. Save. GitHub will provide a public Pages URL.
6. Later, in Settings > Pages > Custom domain, enter the domain you purchased and follow the DNS instructions from your domain provider.

The website uses relative file paths and is ready for GitHub Pages.
